Cours de JavaScript, du débutant à l'expert, incluant des exercices pratiques. Le programme se compose de 5 modules :

1.  **Fondamentaux** : variables, types, opérateurs, structures de contrôle, fonctions.
2.  **Structures de données** : tableaux, chaînes, objets, `this`, prototypes, classes/POO.
3.  **ES6+ Avancé** : closures, modules, Map/Set, générateurs, regex, JSON, gestion des erreurs, nouveautés ES2020-2025.
4.  **Asynchrone & DOM** : manipulation du DOM, événements, callbacks, Promises, async/await, event loop, Fetch API.
5.  **Projets pratiques** : 4 applications complètes (To-Do List, Quiz, Météo, Panier e-commerce), ainsi que les bonnes pratiques, le débogage et Node.js.
